# キャラ固有の勝利ポーズ

`motoneta1.md` の人物像を基準に、全10キャラの「決め動作 → 保持ポーズ」を個別に定義する。
**勝利ポーズ自体はゲーム用の翻案**。下記の仕草がすべて原文で勝利時に行われた、という意味ではない。
通常キャラに `motoneta2.md` の後の人格を混ぜず、覚醒三重だけはその登場場面を参照する。

## 実装上の約束

- `Look.winPose` はキャラID。`CharDef.look` では必須にし、汎用 `cheer / cool / peace` へ自動的に割り当てない。
- `src/game/sprites.ts` の `resolveVictoryPose()` が全員の動作を定義する。未指定の背景人物は平静な待機へ戻す。
- 通常三峰の目つき・眉・赤面は勝利ポーズ内だけの差分にする。普段の顔や、承認済みの応援版の表情を変更しない。
- 目と口を独立させる。数理は `face: 'normal', mouth: 'flat'`、内藤は `mouth: 'subtleSmile'`。共通の `face: 'smile'` を勝利に流用しない。
- `DrawOpts.poseT` は勝利開始からの経過時間。対戦では `Fighter.stateT`、タイトルのデモでは表示サイクル内の時間を渡す。長い試合でも決め動作を途中から始めない。
- 決め動作は一度だけ。その後は保持姿勢の呼吸・ペン回しなどだけを続ける。
- 頭の向きは描画だけの変換。三峰がそっぽを向いても、ゲーム上の `facing` や当たり判定を変更しない。
- 手元・小物・頭の向き・口元は解決済みのポーズに含まれる。[スプライトシート](sprites.md) のキーにも入るため、ペン回しがキャッシュで止まらない。生の `poseT` はキーにしない。
- 内藤の超必殺は別の `observe` ポーズ。勝利用の本を閉じる動作を超必殺で発火させない。
- 勝利台詞・勝敗処理・技の性能・オンライン同期・JPG立ち絵は変更しない。

## 回帰テスト

`tests/victoryPoses.test.ts` で以下を確認する。

- 全員に本人の勝利定義があり、仕草・表情が区別されていること。
- 両馬の拳の突き上げ、通常三峰の腕組み・赤面・顔そらし。二人の勝利時に提示用の小物が出ないこと。
- 通常三峰の前腕の中心線を水平に保ち、高さの差は3 px、重なる範囲は6 px以上とすること。斜めの腕や離れた帯、外へ突き出た拳に戻さないこと。口の6×2 pxの線と、顔をそらす時点・向きは維持すること。
- 数理の全コマで笑顔・ピース・万歳にならず、ペンの4コマが実際に異なること。
- 内藤の本の開閉、櫻の変身中の持ち物、塀の視線、応援版の頭だけの反転、覚醒三重の下げたハンマー。
- 11種類の見た目 × 16時点 × 左右 × フラッシュの **704パターン** で、直接描画とシートのピクセルが一致すること。
- 全キャラで実際のKOから `win` に移行し、`Renderer` が `stateT` のコマを描くこと。
- 保持モーションの再利用、メモリ上限、内藤の超必殺との分離。
