# キャラクターのスプライトシート描画

キャラクターは、既存のドット絵コードから **実行時に生成するスプライトシート** を使う。
手描きの連番 PNG を新しく用意する方式ではない。絵柄・動き・色替えを保ち、毎フレーム
数百回の `fillRect` を実行していた部分を、キャッシュ済みなら **1回の `drawImage`** に置き換える。

## 構成

- `src/game/sprites.ts`
  - `drawFighter()`：従来と同じ呼び出し口。タイトル・対戦・背景人物・残像・代替立ち絵から共通で使う。
  - `resolveFighterFrame()`：ポーズ、攻撃フェーズ、瞬き、髪・ネクタイの揺れ、汗、鉢巻、Python の動きを描画状態に変換する。
  - `drawFighterPixels()`：元の作画コード。シートのコマ生成と、シートを使えない環境での直接描画に使う。
- `src/game/spriteSheet.ts`
  - `SpriteSheetCache`：矩形を記録して実際の描画範囲を測り、透過 Canvas にコマを詰める。
  - 原点は従来と同じ「足元中央」。コマごとにオフセットを保持するので、振り上げた紙、長い武器、倒れた姿も欠けない。

## 再利用とメモリ

- 必要になったコマだけを遅延生成する。起動時に全キャラ・全ポーズを作らず、大きな PNG も配布ファイルへ追加しない。
- キーは `Look` 全体、解決済みの描画状態、白フラッシュの有無。生の時刻 `t` はキーにしない。
- 見た目に関係ないアニメーション値は除外する。フレームを間引いたり、元の動きの周期を変更したりはしない。
- 色替え・変身は別のコマになる。同じ `Look` オブジェクトを編集した場合も更新される。
- 位置・左右反転・透明度は描画時に適用し、それぞれの組み合わせでコマを増やさない。
- **256×256 px のページを最大128枚（RGBA画素分で32 MiB）**。満杯なら、最近使われていないページとそのキーを再利用する。ブラウザやGPU側の管理領域・一時コピーは別途必要。
- ページを小さくしているのは、プレイ中に新しいコマを追加する際の Canvas のコピー／転送コストを抑えるため。
- 1 px の透明な余白を付け、`imageSmoothingEnabled = false` でドットを補間しない。
- Canvas が確保できない場合や、将来追加された絵がページに収まらない場合は直接描画へ戻す。画像を切り捨てたり、ゲームの進行を止めたりしない。

初回生成にはコストがあるため、効果は端末やキャラの組み合わせによって異なる。
背景・飛び道具・一般のエフェクト、ゲームロジック、当たり判定、オンライン同期は変更していない。
選択画面などの JPG 立ち絵もそのまま。

### 透明度

無敵・起き上がり・残像の透明度は、完成したコマ全体に一度だけ適用する。
従来の直接描画で起きていた「半透明のパーツが重なる場所だけ濃くなる」状態にはしない。
明示的な `alpha` がない場合は呼び出し元の透明度を使い、描画後に Canvas の状態を戻す。

## 絵や動きを変更するとき

- 作画は引き続き `drawFighterPixels()`、ポーズは `resolvePose()` を編集する。
- **時刻で変わる要素は `resolveFighterFrame()` に追加し、作画側ではその結果を使う。** 作画内で独自に時刻を読むと、キャッシュキーに現れない動きが止まる原因になる。
- 大きい武器や新しいポーズを追加したときは、下記の比較テストの対象にも加える。
- キャラ固有の勝利動作と原文の根拠は [勝利ポーズ仕様](victory-poses.md) を参照。`poseT` で開始時点を揃え、解決した仕草・口元・手元だけをキーに含める。

## 検証

```sh
npm test
npm run typecheck
npm run build
```

`tests/sprites.test.ts` はテスト用の `@napi-rs/canvas` を利用する（ブラウザ向けバンドルには含めない）。
13種類の見た目（全10キャラ・変身姿・背景人物）×全34ポーズ×3フェーズ×左右の **2,652パターン** を比較する。
白フラッシュや異なる時刻も含め、ページ再利用後も直接描画とピクセルが一致すること、
既存の全コマがシートから描画されることを確認する。別途、キャッシュ再利用・容量上限・
色替え・各種アニメーション・透明度・確保失敗時のフォールバックもテストする。

Vite 開発プレビューのブラウザコンソールでは次のように使用状況を確認できる。

```js
const sprites = await import('/src/game/sprites.ts');
sprites.getSpriteSheetStats(); // pages, frames, bytes, hits, misses, evictions, disabled
sprites.clearSpriteSheets();  // 開発用：画像・キーを破棄して、次の描画から生成し直す
```
